# **FPS Prototype**  
*A minimal first-person shooter demo featuring core mechanics*  

![Unity](https://img.shields.io/badge/Engine-Unity-000000?logo=unity)  
![C#](https://img.shields.io/badge/Code-C%23-239120?logo=c-sharp)  

**Key Features:**  
- ✅ Basic FPS controller (movement, camera look)
- ✅ Weapon system (3 gun types: revolver, machine gun, rocket launcher)
- ✅ Target damage system (hit detection, health bars)
- ✅ Simple enemy AI (stationary targets with damage reaction)
